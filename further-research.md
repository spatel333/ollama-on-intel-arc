# Further Research

## Terms
```
UMA - Unified Memory Access

The CPU & GPU share memory, as opposed to Dedicated VRAM which seperates GPU memory from the CPU. 
This is done at the hardware level, not the architecture level. So just because we use the __xe__ library, does not mean we'll have UMA.
```
